ANTWERP NETBALL CLUB — FINAL WEBSITE

This is the complete bilingual website package for Antwerp Netball Club.

Included:
- English / Nederlands language switch
- Home page
- About Us dropdown
  - Antwerp Netball Club
  - Discover Netball
- Discover Netball story, history, world map, court and positions
- Official World Netball Rules link
- Sporting A recognition
- Training times and KdG Campus Zuid venue
- Membership and pricing for 2026/27
- Games & Tournaments
- Tri-Country Cup (TTC) 2026/27 dates and clubs
- Contact details and social links
- Custom Try Netball form connected to the Google Apps Script web app
- Club photos and logo

DEPLOYMENT
1. Upload/replace the website files in the GitHub repository:
   antwerp-netball-club/antwerp-netball-club-website
2. Keep the files/folders in the same structure, including the images folder.
3. Netlify is connected to the main branch and should deploy the new version automatically.
4. If Netlify is paused because of credits, resume/upgrade the plan first, then push the final files.

The Try Netball form uses the existing Google Apps Script Web App endpoint already configured in index.html.
